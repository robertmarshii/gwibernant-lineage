# Gwibernant / Robb — Working Springer Lineage Explorer

Interactive research map of working English Springer Spaniel pedigrees, beginning with the older Gwibernant / Robb lines.

**Open the website:** If GitHub Pages is enabled, visit [Gwibernant Lineage Explorer](https://robertmarshii.github.io/gwibernant-lineage/).

## Explore
- Search pedigree names; pan and zoom across the family tree.
- Click dogs to inspect relationships and pedigree source links.
- Identify branches linked to Kenine Robb of Rytex (KR).
- Distinguish confirmed KR descendants from branches still under investigation.

## Status and limitations
This is an *investigative lineage map*, not an authoritative or comprehensive Kennel Club pedigree. Some relationships remain provisional or unverified; colour coding must not be interpreted as proof that a dog is KR-free. A KR-free breeding recommendation requires both parents' complete pedigrees.

## Publishing with GitHub Pages
1. Make the GitHub repository **Public** if you want to share its source openly.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/(root)`, then **Save**.
5. Once GitHub finishes publishing, open `https://robertmarshii.github.io/gwibernant-lineage/`.
